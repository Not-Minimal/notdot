📊 OPERADOR + MOVIMIENTO / TEXTOBJECT

     OPERADOR + MOVIMIENTO = ACCIÓN

     d: Eliminar              y: Copiar               c: Cambiar
     ├─ dw: palabra           ├─ yw: palabra          ├─ cw: palabra
     ├─ d$: hasta fin línea   ├─ yy: línea            ├─ cc: línea
     ├─ dd: línea             ├─ y$: hasta fin línea  ├─ c$: hasta fin línea
     └─ d5w: 5 palabras       └─ yG: hasta fin arch.  └─ c5w: 5 palabras

     OPERADOR + a/i + OBJETO = ACCIÓN      (a = con bordes, i = interior)

     ┌───────┬──────────────────────────┬────────────────────────────┐
     │ Obj.  │ Qué es                   │ Ejemplo                    │
     ├───────┼──────────────────────────┼────────────────────────────┤
     │ f     │ Función (treesitter)     │ daf  borra la función      │
     │ c     │ Clase (treesitter)       │ yac  copia la clase        │
     │ o     │ Bloque / if / loop       │ cio  cambia el if          │
     │ a     │ Argumento                │ dia  borra un argumento    │
     │ q     │ Cualquier comilla        │ ciq  cambia el string      │
     │ b     │ Cualquier paréntesis     │ dab  borra (...)           │
     │ t     │ Tag HTML/JSX             │ cit  cambia el contenido   │
     │ w / p │ Palabra / párrafo        │ diw, yap                   │
     └───────┴──────────────────────────┴────────────────────────────┘

     Modificadores:  n = siguiente   l = anterior
          canf → cambia la SIGUIENTE función
          dilq → borra dentro de las comillas ANTERIORES

🌿 GIT WORKFLOW

1. VER CAMBIOS:
     <Space>gn: Siguiente hunk
     <Space>gp: Hunk anterior
     <Space>ghp: Preview del hunk

2. STAGE (preparar cambios):
     <Space>gs: Stage hunk (o selección en visual)
     <Space>gS: Stage buffer completo
     <Space>gu: Deshacer stage

3. REVISAR:
     <Space>dvo: Abrir Diffview
            ↓
        [Revisar todos los cambios]
            ↓
     <Space>dvc: Cerrar

4. HISTORIAL:
     <Space>dvf: Historial de archivos
     <Space>gc:  Commits

5. BLAME (ver quién cambió):
     <Space>gb: Blame de la línea
     <Space>gtb: Blame permanente on/off

🎓 EJERCICIOS PARA PRACTICAR

1. NAVEGACIÓN (5 min):
   - Abre un archivo: <Space><Space>
   - Salta al final: G  /  inicio: gg
   - Ve a línea 42: :42
   - Salta entre funciones: ]f  [f

2. EDICIÓN (5 min):
   - Copia línea: yy   Pega: p   Elimina: dd
   - Cambia el cuerpo de una función: cif
   - Borra un argumento: dia
   - Rodea una palabra con comillas: saiw"

3. BÚSQUEDA (5 min):
   - En el archivo: /palabra, n
   - En el proyecto: <Space>sg
   - Reemplaza: :%s/viejo/nuevo/gc

4. VENTANAS (5 min):
   - Split horizontal: qq   vertical: sv
   - Navega: Ctrl+hjkl
   - Cierra: Ctrl+w q

5. GO (10 min):
   - Escribe fmt.Println sin import y guarda (:w): el import aparece solo
   - Crea un _test.go y corre el test: <Space>tt
   - Pon un breakpoint y depura: <Space>db, <Space>dc, <Space>dn

6. GIT (5 min):
   - Ve cambios: <Space>gn
   - Stage: <Space>gs
   - Revisa: <Space>dvo
   - Blame: <Space>gb

💪 PRO TIPS

1. Repite el último cambio:
   .

2. Macro recording:
   qa (start)
   ... acciones ...
   q (end)
   @a (execute)    @@ (repetir)

3. Búsqueda sin distinguir mayúsculas:
   /\cpatrón

4. Reemplaza lo último que buscaste:
   *  (busca la palabra)  →  :%s//nueva/g

5. Edición en columna (visual block):
   Ctrl+v → selecciona → I o A → escribe → Esc

6. Viaje en el tiempo (undo persistente):
   :earlier 10m     :later 10m

7. Volver de un salto (gd, ]f, búsqueda):
   Ctrl+o (atrás)   Ctrl+i (adelante)
